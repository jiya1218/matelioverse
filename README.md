# Matelioverse — India's Smartest Building Materials Platform

A modern, high-performance frontend redesign for [Matelioverse](https://matelioverse.com/), styled to match the layout, user experience, and structure of [Madoverbuildings (MOB)](https://madoverbuildings.com/).

## 🚀 Features
- **Sticky Double Header**: Location selector, dynamic rotating search bar with AI button, referral widget, login, and cart counter.
- **Hero Carousel**: Auto-rotating promotional slides with capsule indicator dots.
- **2-Row Category Grid**: 15 building material categories in an 8 + 7 layout with clean product renders.
- **Dual Promo Cards**: Magic AI quote in 60 seconds & CredEzy Line of Credit.
- **Featured Private Label Brands**: Strongfab, Xtra-Cem, TileTrendz, Hydrolines, ReflectoGlass, and Tuffar.
- **Product Carousels**: Borderless e-commerce product cards with discount badges, price comparisons, and quantity selector ADD buttons.
- **Why Choose Matelioverse**: Value pillars on tech, scale, smart store retail, and stronger margins.
- **Testimonials & Partners**: Real customer reviews, industry partners, and trust highlights.
- **Dark Footer**: Full company links, contact info for Ahmedabad Head Office, Bengaluru & Mumbai hubs.
- **Functional Multi-Page Setup**:
  - `index.html` — Homepage
  - `about.html` — About Us
  - `categories.html` — Categories & Brands
  - `partner.html` — Partner With Us
  - `contact.html` — Contact Us

## 🛠️ Tech Stack
- **HTML5** & **Vanilla CSS**
- **JavaScript (ES Modules)**
- **Vite** (Dev Server & Bundler)

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally (Dev Server)
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
